## 4. Notes / caveats
- S4 immutability is enforced at THREE levels: no update API after submit
  (service state machine), the conditional DB trigger (raw UPDATE/DELETE of a
  final version row raises 'immutable' — proven by integration test against
  the real DB), and audit fields on every row.
- "Assigned evaluator" for document ACL = has an evaluations row for any
  proposal of the owning team; "assigned mentor" = mentorships row. Both
  proven in the S2 matrix test (cross-team member, cross-institution SPOC,
  unassigned mentor, unassigned evaluator, no-team participant all DENIED;
  super_admin ALLOWED).
- Invites: no token table in the schema, so acceptance is team-scoped
  (POST /teams/:id/accept) with the service validating the pending invite
  row + same institution (D22). The registry's original
  /invites/:token/accept entry was replaced.
- E2E browser suite (Playwright full journey) is P9 per plan — this phase's
  HTTP proof is the smoke above.
- Demo seed now creates leader(male)/member(female)/spoc/mentor/evaluator/
  admin with genders and SPOC-institution fixed (needed for the min_female
  and SPOC-same-institution rules).
