## Notes / caveats
- Sandbox Postgres uses loopback `trust` (sandbox only; production = SCRAM,
  real credentials via secrets — see PROVIDER_RESEARCH.md §9).
- TRUSTED_PROXY_COUNT defaults to 0: without a trusted proxy, client IP is
  always the socket address and x-forwarded-for is IGNORED (proven in §4).
  Behind Caddy on the VM, set TRUSTED_PROXY_COUNT=1 (single hop).
- Session cookie attributes (HttpOnly, Secure, SameSite=Strict, Path=/) are
  enforced in the route layer in P4; the session store itself is proven here.
- CSRF guard (csrf.ts) unit-tested in §3; wired into mutating routes in P4.
- UNVERIFIED: nothing in this phase depends on external providers.
